# 钢材表面缺陷类增量学习系统 V1.0

本目录为可独立演示的精简工程，附旧三类基座、日常六类dual最佳模型，以及60张示例图片。

## 启动

在已配置PyTorch训练环境的终端运行 `python -B launch.py`，也可以双击“启动系统.bat”。
端口默认自动选择7860至7880中的空闲端口；浏览器自动打开，控制台同时显示地址。
界面空注册库仍然可以打开，日常检测默认选中随包提供的第45轮dual。

## 增量演示

按“项目与基座 → 创建增量任务 → 训练监控 → 评估与版本 → 缺陷检测”操作。
演示默认每个新类5张、每个旧类回放5张、训练1轮、batch=2；这些数值是演示配置。
正式训练请换用完整数据，并设置真实样本额度与训练轮数。
任务和模型版本记录运行后生成于 `app_runs/workflow/`。

## 环境

已验证环境：Windows、Python3.12、torch2.5.1+cu121、torchvision0.20.1+cu121、Gradio4.44.1。
先安装匹配的PyTorch与torchvision，再安装 `requirements.txt`。
随包CUDA扩展仅适用于与原工程匹配的Windows CPython3.12/PyTorch环境。
其他环境可使用保留的PyTorch回退路径，或在 `models/ops/` 重新编译。
应用启动后直接从完整存档恢复backbone，不重复下载torchvision初始化权重；已有匹配运行环境时可离线演示。

材料、完整操作步骤与验证说明位于本目录上级的“01_登记材料”和“03_运行说明”。
