# 环境与启动

本包已移除两份权重中的旧优化器状态，模型参数逐张量保持一致。运行环境复用已经配置好的Python训练环境，不包含解释器与GPU驱动。
已验证：Windows、Python3.12.7、torch2.5.1+cu121、torchvision0.20.1+cu121、Gradio4.44.1、Plotly5.24.1。

在“02_软件源码”中打开PowerShell：

```powershell
python -m pip install -r requirements.txt
python -B launch.py
```

如果默认python不是训练环境，请运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\启动系统.ps1 -Python '实际训练环境的python.exe路径'
```

启动脚本自动寻找7860至7880中的可用端口，避免与原工程正在运行的界面冲突。
当前机器已有环境时可以直接启动，无需再次安装。缺少CUDA时可选择CPU进行演示，速度更慢。
示例增量仅训练1轮，用于观察数据校验、真实训练进度、前后评估与版本保存。
日常检测默认使用随包的原dual第45轮；增量演示完成不会自动覆盖它。

本版本支持本项目兼容旧三类基座的一次类别增量。其他模型家族需要开发适配器，不能只修改文件名或类别名。
